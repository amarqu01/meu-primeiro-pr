# meu-primeiro-pr

Repositório de exemplo para praticar o fluxo de Pull Request com o GitHub CLI.

## Sobre

Este repositório foi criado para demonstrar o processo completo de contribuição via PR:
criar uma branch, fazer uma mudança, e abrir um Pull Request.

## Como contribuir

1. Faça um fork ou clone do repositório
2. Crie uma branch descritiva: `git checkout -b minha-melhoria`
3. Faça suas alterações e commit: `git commit -m "descrição da mudança"`
4. Envie para o GitHub: `git push origin minha-melhoria`
5. Abra um Pull Request pela interface do GitHub ou com `gh pr create`
